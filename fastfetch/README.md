# Fastfetch

Custom Fastfetch configuration and ANSI-coloured ASCII artwork for the **ZERO / Forgotten Knight** theme.

---

### ASCII Art

- **File:** `ascii/arch.txt`
- **Dimensions:** 56 columns × 23 rows
- **Colours:** ANSI true-colour (24-bit)

---

### Setup

1. Install [Fastfetch](https://github.com/fastfetch-cli/fastfetch).
2. Place `config.jsonc` and the `ascii/` folder in your Fastfetch configuration directory.
3. Run `fastfetch`.

---

**Requirements:** Fastfetch and a terminal supporting ANSI true-colour.
